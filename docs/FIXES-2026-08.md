  polygons are absolute (`vertexFrame: 'absolute'`) and are rebased body-local
  with a rotation-inverse exactly once; already-local vertices declare
  `vertexFrame: 'local'` and are never shifted.

  engine semantics, including the `1e-6` magnitude floor fallback.

  accounting: mid-run deaths count as compared data, so faithful replays
  compare every tick (`ticksCompared === ticks.length`, `skippedNoData === 0`);
  the WDB replay pair is deliberately death-agnostic because death presence is
  geometry-dependent.
